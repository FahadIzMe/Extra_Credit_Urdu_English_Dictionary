# Extra_Credit_Urdu_English_Dictionary
- This is the extra credit Course Project from our first semester that I made alongside the normal one. It is a primitive English to Roman Urdu translation program with limited resources.
- This was a second project "Urdu to English Dictionary" which we were supposed to solve for extra credit if we wanted it.

## Rules

1. We were not allowed the use of built-in strings or the use of string library.
2. We were not allowed to write any code inside main except the standard structure and function calls.
3. We were required to write comments similar to the comments of our lecturer Dr. Ali Mirza.
4. Only the keywords, statements and directives that were used or taught during lectures were allowed.
